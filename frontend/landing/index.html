01

Agents are starting to hold money. Every way to give them that today is broken in one of two directions.

Full access

An API key or a wallet approval that lets the agent do anything.

One bug or one prompt injection and everything is gone.

Approve every action

A human signs every transaction.

Then the agent isn’t autonomous, and the human is the bottleneck at 3 a.m.

02

On 1inch Aqua the problem is sharper: a strategy is immutable, so someone has to keep closing and reopening it.

There is no “edit position” on Aqua. Adjusting a range means dock() the old strategy, then ship() a new one.

Whoever runs that loop for you holds dock authority, and whoever can dock can pull the whole virtual balance. To let an agent manage an Aqua position at all, you hand it the key to your money. That is what you hand a bot today: all or nothing.

03

The idea: decay, not expiry. Expiry is a cliff. Decay is a slope.

Leash gives the agent a permission that shrinks by itself. The number is how much the market can take from your position right now. It halves every 24 hours since a verified human last showed up, interpolated inside the day so there are no steps, and is cut to zero at 72 hours. Nobody but a human can top it up.

How it’s built. ENS holds the permission. World makes renewal human-only. A SwapVM opcode enforces the cap inside every trade.

                                           └─ verify()          ──► Vault.lastVerified
agent/loop.mjs ── ship / dock ──► Vault (Aqua maker, holds the tokens) ──► 1inch Aqua
market (any taker) ── swap ──► MandateAquaRouter ── 0x2f MandateGate ──► Vault.mandate() ──► ENS roles

        05
        
This isn’t a UI rule. It’s a SwapVM opcode that runs inside every quote and swap.

        
Read the maker’s mandate, revert if revoked or empty, trim the USDC leg to what is still allowed. Built-in guards say yes or no; this one says how much. It runs in quotes too, so there is no path around it.

        07
        
    Three sponsors, each load-bearing. Each integration changed the design.
    
      
    
      
    
        
    
          
    ENSv2
    
          
    Holds the permission.
    
          
    The mandate is a role bit on a name you own in your own UserRegistry. Token admin bits cannot be delegated in ENSv2, so the backend holds tier-admin at the registry root: it can set tiers but never touch MANDATE. Name expiry kills all roles automatically.
    
          
    vs a signature: a signature can’t be revoked; a live role can, and anyone can read it.
    
        
    
        
    
          
    World ID
    
          
    Makes renewal human-only.
    
          
    Without it the agent would renew its own permission and decay is theatre. Replay protection is the signed request nonce, single-use, not the nullifier, because the same human must be able to come back. The nullifier binds one human to one vault.
    
          
    Selfie Check 2,000 · passport 7,500 · Orb 15,000 USDC.
    
        
    
        
    
          
    1inch Aqua · SwapVM
    
          
    Enforces it inside the trade.
    
          
    The Aqua router shipped with no permission instruction at all. MandateGate is one, and it answers how much rather than yes/no. The engine, XYCSwap, Aqua and taker traits are 1inch’s, unchanged.
    
          
    vs the Decay opcode: Decay shrinks what’s offered; ours shrinks what’s still allowed.

Then more curves, and any recurring authority that should die when the human stops showing up: payroll streams, grant disbursement, treasury limits.
